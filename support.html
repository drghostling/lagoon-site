Support

Lagoon needs macOS 14 or later.

Contact

Open an issue at github.com/drghostling/lagoon-site/issues. Please say which Mac and macOS version you use and what you expected to happen.

There is no transcript, only audio

Live transcripts need Dictation switched on: System Settings → Keyboard → Dictation. Lagoon also asks for microphone and speech recognition access the first time you record; if you said no, allow it in System Settings → Privacy & Security.

Where are my recordings?

In Documents/Lagoon, one folder per recording with the audio (.m4a) and the transcript as .txt, .md (with timestamps) and .srt (subtitles). The folder is named after the first words you said.

Which languages are supported?

By default Lagoon listens for your system languages and English. In Settings → Speech languages you can choose up to five. The live transcript listens for the first two at once; the optional Whisper pass uses all of them.

What is “Improve with Whisper”?

An optional second pass that re-transcribes a saved recording with the open-source Whisper model. It is off by default; turning it on in Settings lets you download a 480–626 MB model once (you are asked first). It never replaces the live text: the card keeps both and lets you switch.

Shortcuts

⌃⌥R starts or stops a recording, ⌃⌥I opens or closes the island. Lagoon also answers to lagoon:// URLs, so you can start timers from Shortcuts: lagoon://timer?minutes=25&title=Focus.
